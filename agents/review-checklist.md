# Review checklist

- [ ] Scope and terminology are correct.
- [ ] Existing records were searched before creating new IDs.
- [ ] Factual claims link to traceable sources.
- [ ] Evidence status distinguishes attestation, interpretation, proposal and creative coinage.
- [ ] Rights and consent are checked for intended use.
- [ ] Variants, registers, dates and scope are preserved where known.
- [ ] Uncertainty and counterevidence are visible.
- [ ] Schema validation and relevant regression tests ran.
- [ ] Downstream impacts are identified.
- [ ] No source repository history or files were overwritten.
- [ ] Release notes accurately state what was and was not tested.
