# Concept records

Concept records use `schemas/concept.schema.json` and stable `con-` identifiers. A concept is a framework's organizing label, not evidence that a linguistic form exists or that two communities use the same category.

One concept record currently defines nominal plurality as an organizing concept. It does not itself establish any language-specific form. Add factual or linguistic claims only with source IDs and precise source locations in supporting records. A record may remain draft with an empty `source_ids` array; an accepted record must have at least one resolvable source ID. Do not create empty-array fields or use a concept record to introduce an unsourced etymology, translation, or classification.
