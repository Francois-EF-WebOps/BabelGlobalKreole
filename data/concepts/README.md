# Concept records

Concept records use `schemas/concept.schema.json` and stable `con-` identifiers. A concept is a framework's organizing label, not evidence that a linguistic form exists or that two communities use the same category.

No concept records are published yet. Add one only when its scope and intended use are clear. If the definition makes a factual or linguistic claim, attach source IDs and precise source locations in the supporting source records. A record may remain draft with an empty `source_ids` array; an accepted record must have at least one resolvable source ID. Do not create empty-array fields or use a concept record to smuggle an unsourced etymology, translation, or classification.
