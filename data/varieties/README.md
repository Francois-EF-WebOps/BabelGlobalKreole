# Variety records

This directory contains only variety records supported by inspected sources. The current record describes Martinican Creole using a Glottolog dialect entry and an APiCS dataset. It is not a complete variety inventory.

Create a variety record only when a fetched source supports the distinction and the record can point to precise source locations. Do not use an empty JSONL file to reserve names. Candidate coverage that cannot yet be supported is tracked in [the language coverage register](../../docs/language-coverage.md).

The schema allows optional register metadata as free text plus source IDs. Register terms such as basilect, mesolect and acrolect are not a fixed taxonomy and must not be applied across all Creoles by default.
