# Language and variety registry

`varieties.jsonl` is a candidate-scope inventory, not a sourced classification catalogue. Current entries are provisional placeholders linked to matching provisional language records only to satisfy the record relationship; this is not acceptance of a scholarly or community classification.

No countries/regions, period, orthography, speaker estimate, parentage, lexifier, contact-language, Glottocode, or ISO code is asserted without a source. Add source IDs and precise source locations before changing any placeholder into an accepted claim. If sources disagree, preserve the disagreement and use `disputed` only when the evidence of scholarly disagreement has itself been recorded.
