# Lexical records

Store validated entries using `schemas/lexical-entry.schema.json`. Keep lexical data separate from the resource index at `data/resources/resources.jsonl`.

## Import rules

Before copying a word, definition, example, pronunciation, or dataset:

1. Record the exact source URL, access date, and entry/page/section locator.
2. Verify source attribution, license, third-party rights, and relevant AI-use permissions separately.
3. Treat aggregators and directories as discovery tools, not authoritative sources or blanket reuse grants.
4. Label evidence clearly: source-attested, editorially corrected, proposed, or creative.
5. If rights or provenance are uncertain, link externally rather than copying.
6. Validate entries against the lexical schema and repository checks.

## Coverage

The resource index includes Mauritian-focused links and global references for Haitian, Jamaican, Seychellois, and Papiamentu, plus cross-Creole discovery and comparative resources. This is an initial index, not comprehensive global coverage.

Expand systematically across Creoles associated with French, English, Portuguese, Spanish, and Dutch, while documenting other contact-language traditions without assuming that every contact language is a Creole. Shared lexifier does not prove lexical equivalence.

Use APiCS primarily for comparative structural information and cited references. Check each WOLD, Creole NLP, ASJP, dictionary, and linked dataset separately for actual language coverage, source provenance, and reuse terms. Resource links do not themselves authorize lexical imports.
