# Language records

`languages.jsonl` contains sourced catalogue-level language records, not a comprehensive list of every Creole language. Each accepted record has a fetched Glottolog source record with the Glottocode and ISO 639-3 value displayed on that page. APiCS source records are included where the corresponding page was inspected in this pass.

Candidates without a verified, distinct catalogue entry belong in [the language coverage register](../../docs/language-coverage.md), not as unsourced data records. A sourced identifier does not prove every classification, lexifier, substrate or community-preferred name; those claims need their own source IDs. Unknown optional fields are omitted.
