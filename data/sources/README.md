# Source ledger

Record source metadata and rights status before relying on a source. Listing a source does not mean its content is approved for redistribution. Use `schemas/source-record.schema.json`.

Canonical machine-readable source records are stored in [`sources.jsonl`](sources.jsonl). Each source record identifies the exact URL, access date, relevant page location, rights review state and AI-use permissions. A source record describes provenance; it does not grant permission to ingest the source's underlying content.
