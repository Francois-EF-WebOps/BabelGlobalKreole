# Data status

No complete language corpus or lexicon is claimed at this stage. Add records only with stable IDs, traceable sources, scope, evidence labels, review status, and rights metadata. Do not fabricate seed records to make the project look populated.

Planned release bundles:
- `data/lexicon/*.jsonl` — lexical records validated against `schemas/lexical-entry.schema.json`
- `data/sources/*.jsonl` — source records validated against `schemas/source-record.schema.json`
- future language and variety records — after their schemas and external identifier mappings are reviewed

Every release should pin its schema/framework version and publish validation results and hashes. See [data license policy](../DATA-LICENSE.md) before adding source-derived content.
