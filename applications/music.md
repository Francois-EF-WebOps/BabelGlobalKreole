# Music application contract

This file is retained as a compatibility entry point. The current detailed rules are in [Music, lyrics and poetry](music-poetry/README.md).

Music is a first-class application, not the framework's defining boundary. Creative output must be labelled separately from attested evidence, and third-party lyrics, recordings, samples or source text must not be ingested without permission for the exact use. Owner-contributed work requires owner-selected license and AI-use flags before publication.
