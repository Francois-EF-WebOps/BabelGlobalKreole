# Release process

Freeze candidate records and schemas; run validation and relevant evaluation cases; audit sources, evidence labels, rights, privacy and attribution; review breaking changes and migrations; generate a release manifest listing framework/schema versions, record IDs, validation output, build date and limitations; obtain required human/community review; tag and publish notes; update project registry and consumers; monitor corrections.

A release is a versioned snapshot, not a claim of completeness or universal validity.
