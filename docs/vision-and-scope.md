# Vision and scope

## Owner-approved intent (verbatim)

BabelGlobalKreole is a public, permanently maintained, evidence-grounded knowledge and interoperability layer for Creole languages. It  from Creole (Kreol) and expands to French-lexifier Creoles of the Caribbean and Indian Ocean, then to Creoles with other European lexifiers (English, Portuguese, Spanish, Dutch), recording non-European contributions where documented. It links to existing scholarly and community resources instead of duplicating them. Creative applications (priority: music, lyrics, poetry; then film/series scripts; then programming and software localization) consume the framework and never define it. Creative output is always labelled separately from attested evidence.

## Vision
Build durable, portable infrastructure that lets people and software discover, interpret, compare, evaluate and responsibly apply knowledge about Creole languages and related language-design work.

## Working meaning of Global (K)Creole
A project umbrella for a framework that can represent multiple Creole languages, varieties, contact histories and language-design projects. “(K)” is a project label pending a documented terminology decision; it is not presented as an established linguistic classification.

## In scope
Language/variety metadata; sourced claims and comparative evidence; lexical, grammatical, pronunciation and usage records; labelled convergence/constructed-language proposals; rights, consent, uncertainty and provenance; evaluation and regression tests; portable agent/LLM interfaces; application contracts; governance and change propagation.

## Out of scope
Declaring all Creoles one language; replacing community institutions; publishing restricted datasets; treating fictional language as evidence about real languages; defining the project through one application; claiming autonomous execution without a verified runner, permissions, credentials and monitoring.

## Success indicators
Contributors can find the right scope quickly; records validate locally; factual claims carry provenance; schema changes identify affected consumers; applications consume versioned snapshots without proprietary models; external reuse and corrections are recorded honestly.
