# Terminology

| Term | Meaning here | Not to be confused with |
|---|---|---|
| Babel / Global (K)Creole | Umbrella framework and interoperability project | A single naturally occurring language or endorsed global standard |
| Creole language | Language described as Creole in a specific scholarly/community context | A universal classification without debate or context |
| Language variety | A documented variety linked to a language or speech community | A defective or lesser form |
| Comparative claim | Sourced comparison of forms/structures | Proven common origin inferred from resemblance |
| Convergence proposal | Design proposal for shared forms or conventions | Attested community usage |
| Constructed language | Deliberately designed language with identified scope/authority | Naturally occurring language |
| Mooritian | Working name for fictional/in-world language in *Fresh: Love and Water*, pending project confirmation | Mauritian Creole or the whole framework |
| Application | Consumer such as music, games, teaching or speech | Framework boundary |
| Attested | Directly supported by a traceable source for stated scope | Likely, similar-sounding or model-generated |
| Unknown / undecided | Explicitly unresolved | Permission to guess |

Real languages and varieties retain their own identifiers and sourced metadata. Mooritian is application-specific constructed-language work; design inspiration does not establish historical ancestry. Music is one application alongside education, games, research, speech, translation and publishing.
