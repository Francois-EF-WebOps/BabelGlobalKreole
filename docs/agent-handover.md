# Agent handover

Every task handover must be self-contained and include task ID, objective, canonical scope, exact input records/source locations, allowed paths, forbidden actions, evidence and rights requirements, acceptance tests, uncertainties, expected outputs, review requirement and summary.

## Handover summary
1. What changed.
2. Files/records changed.
3. Sources and rights checked.
4. Tests run and exact results.
5. Limitations and unresolved questions.
6. Downstream consumers affected.
7. Next bounded task.

Agents may discover sources, extract metadata, draft records, propose comparisons, generate tests and validate schemas. They must not independently certify linguistic claims, grant licences, infer consent, announce community endorsement, merge breaking changes or publish restricted data.
