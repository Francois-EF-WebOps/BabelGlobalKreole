# Decision 0001: Framework boundary

- **Status:** Accepted project direction; implementation remains draft.
- **Date:** 2026-10-17.
- **Decision:** Dedicated Babel / Global (K)Creole repository. Music, games, education, speech, translation, research and publishing are applications. MKC remains coordination/discovery. Existing repositories and histories are preserved.
- **Context:** MKC contains coordination and a Babel-to-Mooritian handover. Applied-Creole-Linguistics exists but its purpose/runtime is not verified as the canonical framework.
- **Consequences:** This repository owns framework policies, schemas, evaluation, governance and adapter contracts. Existing artefacts are linked rather than copied until inspected and rights-cleared.
